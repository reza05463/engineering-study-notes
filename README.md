# یادداشت‌های مهندسی کامپیوتر

گزارش‌ها، ارائه‌ها و یادداشت‌های دانشگاهی‌ام را در این مخزن جمع کرده‌ام. موضوعات آن‌ها شامل شبکه، طراحی و آزمون نرم‌افزار، سخت‌افزار و یادگیری ماشین است. بعضی از کارها تمرین طراحی هستند و بعضی دیگر خلاصه مطالعه یا مرور مقاله‌اند.

جدول زیر به نسخه فارسی هر ۱۳ یادداشت پیوند دارد. برای تغییر زبان، از پیوند English یا فارسی در بالای هر یادداشت استفاده کنید.
